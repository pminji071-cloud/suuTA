📌 1. 프로젝트 소개
개발 배경: 정해진 캐릭터로만 플레이하는 단조로운 미니게임을 넘어, 사용자가 직접 전신/상반신 사진을 올려 나만의 네온 뼈다귀 아바타로 즐길 수 있는 맞춤형 게임을 제작했습니다.

핵심 특징:

Google MediaPipe Pose AI: 업로드한 사진의 관절 랜드마크 좌표를 실시간 스캔

영구 저장소 연동: 브라우저 localStorage를 통해 앱을 재접속해도 아바타와 최고 기록 유지

동적 테마 시스템: 점수에 따라 배경 테마와 게임 속도가 단계별로 상승

🎮 2. 사용법
아바타 등록: 우측 보관함에서 .jpg, .png 사진 업로드 ➔ AI 스캔 후 아바타 클릭 시 즉시 적용

조작 방법:

점프: Spacebar 또는 마우스로 게임 화면 클릭 (최대 2단 점프)

숙이기: Ctrl 키 누르기

일시정지: ESC 키

🛠️ 3. 주요 기술 및 기능
Tech Stack: Python, Streamlit, HTML5 Canvas, JavaScript, MediaPipe, Pillow

핵심 기법:

썸네일(300x300) 압축을 통한 대용량 이미지 부하 방지

파이썬 세션과 localStorage 간의 양방향 자동 동기화

캔버스 자동 포커스(canvas.focus()) 적용으로 즉시 키보드 조작 가능
